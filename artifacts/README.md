# artifacts/

Most of this directory is git-ignored: model checkpoints, figures, and logs are
outputs of `code + config + data`, not source. The exceptions below are tracked
because the paper's numbers depend on them and they are small.

| Path | What it is |
|---|---|
| `harmonized_thorough/master_multi_seed_results.json` | Every metric for the 36-run matrix (3 architectures × 4 arms × 3 seeds, both checkpoint criteria). Every number in the paper is recomputable from this file. |
| `harmonized_thorough/compute_environment.json` | GPU, CUDA, and PyTorch versions used for the runs. |
| `harmonized_thorough/predictions/` | Raw `y_true` / `y_pred` (`.npz`) and 5×5 confusion-matrix counts (`.json`) for the ResNet-18 conditions used in the confusion-matrix figures. Regenerated by `scripts/regenerate_confusion_matrices.py`. |
| `tuning/tuning_results_*.json` | Per-trial validation trajectories for the joint, CCSN, and GCD hyperparameter sweeps. Appendix A of the paper. |
| `audit_2026-09-07_independent/report_full36.md` | Independent verification of the 36-run matrix: file hashes, metric recomputation, and a reproduction run. |

Model checkpoints (~5 GB of `.pth`) are not committed. The per-run summary JSONs
produced alongside them are aggregated into `master_multi_seed_results.json`.
